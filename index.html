Política de privacidad

Postiz (uso personal) · Última actualización: 17 de octubre de 2026

Qué es

Esta aplicación es una instalación privada de Postiz que usa una sola persona para programar y publicar su propio contenido en sus propias cuentas de YouTube, Facebook, Instagram, X y TikTok. No está abierta al público.

Qué datos usa

Al conectar una cuenta, la aplicación guarda los permisos de acceso (tokens) que da cada plataforma, las publicaciones programadas y las métricas de esas cuentas. Solo se usan para publicar contenido y leer las estadísticas de las cuentas del propio dueño.

Dónde se guardan

Todo se guarda únicamente en el equipo o servidor propio del dueño. Los datos no se venden, no se ceden y no se comparten con terceros.

Cómo revocar el acceso y borrar los datos

El acceso se puede retirar en cualquier momento desde la configuración de seguridad de cada plataforma. Al desconectar un canal en la aplicación, sus tokens se eliminan.

Privacy Policy

Postiz (personal use) · Last updated: October 17, 2026

What it is

This application is a private Postiz installation used by a single person to schedule and publish their own content to their own YouTube, Facebook, Instagram, X and TikTok accounts. It is not open to the public.

What data it uses

When an account is connected, the application stores the access permissions (tokens) granted by each platform, scheduled posts, and the metrics of those accounts. They are used only to publish content and read statistics for the owner's own accounts.

Where it is stored

Everything is stored only on the owner's own computer or server. Data is not sold, transferred or shared with third parties.

Revoking access and deleting data

Access can be revoked at any time from each platform's security settings. When a channel is disconnected in the application, its tokens are deleted.
